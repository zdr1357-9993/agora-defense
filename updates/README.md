## 작성 규칙
1. 업데이트마다 YYYY-MM-DD-기능명.md를 추가하고 이 색인을 갱신한다. 같은 날짜는 기능명/번호로 구분한다.
2. TEMPLATE.md를 복사해 요청, 실제 변경 파일, 수치 전후, 브랜치·커밋, 검증, 배포, 실험, 남은 작업을 기록한다.
3. 로컬 수정, 커밋, 로컬 서버 반영, 원격 push, Pages 배포, 게임 실험 실행은 각각 별도로 증거와 함께 표시한다. 준비만 했으면 실행 완료로 쓰지 않는다.
4. 실험에는 실제 소스 SHA와 미커밋 변경/데이터 해시, 설정, PID, 완료 판수, 결과·로그 경로를 기록한다.
5. 과거 사실을 덮어쓰지 않고 상태 전환을 날짜·시각(Asia/Seoul)과 함께 추가한다. 확인 안 된 항목은 미확인으로 쓴다.
6. 토큰·키·비밀번호·개인정보는 기록하지 않는다. 기록 폴더를 해당 변경 커밋에 포함한다.
