# 철학사 랜덤 디펜스 (Project AGORA)

철학자 50인을 소환·조합해 도그마를 논파하는 모바일 웹 랜덤 디펜스 프로토타입.

## 실행
```bash
npm install
npm run dev      # http://localhost:5173
```

## 데이터
- 원본은 `data/agora_master.xlsx` 하나. 엑셀만 수정하면 됨.
- `npm run dev` / `npm run build` 때 자동으로 `src/data/*.json`으로 변환되고, 잘못된 ID 참조가 있으면 빌드가 멈춤.

## 구조
- `src/game.ts` 전투 규칙 (웨이브, 합성, 조합식, 원정/대화)
- `src/main.ts` 화면(스테이지 지도·덱 선택·도감·전투)과 입력
- `src/data.ts` 등급별 전투 수치, 원정 배율 등 밸런스 값
- `src/sprites.ts` 철학자/몬스터 픽셀 도트 생성기
- `src/save.ts` 진행 저장(localStorage)

## 게임 구조 (v0.6)
- 1~4성(6~7명씩): 소환 확률 70/22/7/1%, 같은 등급 아무나 3명 → 다음 등급 무작위 (3성 ×3 → 4성까지)
- 4성 = 현대로 들어가는 문: 니체 · 프로이트 · 마르크스 · 프레게 · 키르케고르 · 퇴계 · 혜능
- 5성(거장 11명)·6성(근원: 소크라테스 · 칸트 · 데리다 · 공자 · 붓다)은 📜 조합표로만
- 히든: 바울(5성) → 예수(6성)
- 5성 이상은 골드로 강화(최대 Lv.5, 단계당 공격력 +35%)
- 스테이지 5개, 각 스테이지 카운터가 최종 보스에게 피해 3배
- 확률은 엑셀 `Rates` 시트, 조합은 `Recipes` 시트에서 수정
- QA 모드 기본(10000G, 전 스테이지 해금). `?qa=0`이면 일반 모드

## 성장 (v0.7)
- 🤔 고민방: 철학자를 탭하거나 방치하면 "고뇌"가 쌓임 (스테이지 클리어할수록 방치량 증가, 최대 8시간)
- 🎴 철학자 카드 뽑기(100 / 10연 900 고뇌): 같은 카드 1·2·4·8…장마다 레벨업, 레벨당 전투 공격력 +10%
- 🧰 도구 뽑기(150 / 10연 1350 고뇌): 도감에서 철학자별로 장착, 주인에게 끼우면 찰떡 보너스
- 전투 보상: 웨이브 × 15 + 클리어 300 고뇌
- 수치는 `src/meta.ts`, `src/save.ts`, `src/items.ts`에서 조정
