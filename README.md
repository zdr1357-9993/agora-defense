# 철학사 랜덤 디펜스 (Project AGORA)

철학자 50인을 소환·조합해 도그마를 논파하는 모바일 웹 랜덤 디펜스 프로토타입.

## 실행
```bash
npm install
npm run dev      # http://localhost:5173
```

## 데이터
- 원본은 `data/agora_master.xlsx` 하나. 엑셀만 수정하면 됨.
- `npm run dev` / `npm run build` 때 자동으로 `src/data/*.json`으로 변환되고, 잘못된 ID 참조가 있으면 빌드가 멈춤.

## 구조
- `src/game.ts` 전투 규칙 (웨이브, 합성, 조합식, 원정/대화)
- `src/main.ts` 화면(스테이지 지도·덱 선택·도감·전투)과 입력
- `src/data.ts` 등급별 전투 수치, 원정 배율 등 밸런스 값
- `src/sprites.ts` 철학자/몬스터 픽셀 도트 생성기
- `src/save.ts` 진행 저장(localStorage)

## 게임 구조 (v0.5)
- 5시대(고대·중세·동양·근대·현대) × 13명 사다리 + 히든 2명
- 등급 = 위상. 5성(시대를 연 사람): 소크라테스 / 아우구스티누스 / 칸트 / 비트겐슈타인 / 공자
- 같은 철학자 3명 → 같은 시대 한 등급 위 무작위
- 조합식 = 시대를 건너는 "만남" (예: 아리스토텔레스 + 이븐 시나 → 이븐 루시드)
- 스테이지마다 시대 2~3개를 골라 덱 구성. 다른 시대 철학자는 원정(힘 60%), 현지 철학자 옆이면 대화(100%)
- 스테이지 5성은 그 시대 최종 보스에게 피해 3배
- QA 모드 기본(10000G, 전 스테이지 해금). `?qa=0`이면 일반 모드
