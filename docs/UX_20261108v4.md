## 수정
- 5시대 전투용 실제 이미지 아틀라스 25칸: 배치 타일 2종, 길 타일, 주변 장식 2종.
- 고대 대리석/동양 이끼 돌/중세 라벤더 석재/근대 계몽 학원/현대 캠퍼스.
- 시대별 외곽 풍경 프레임과 대기석 양옆 작은 장식. 배치 가능 영역과 적 경로는 유지.
- 캔버스 CSS border-box에서 3px 테두리 때문에 CSS 실측이 6px 줄어드는 문제 수정.
- 테두리를 레이아웃 크기를 바꾸지 않는 outline으로 이전. 화면 크기와 backing bitmap의 DPR 비율을 일치.
- 전장 전체를 불투명하게 채우고 카메라 이동을 없애 흔들림 때 바닥이 비치는 현상 제거.
- 뽑기를 생성한 리본 두루마리 버튼 → 열기 → 카드 순차 공개로 교체.
- 강한 광선/화면 흔들림/전설 반복 발광 제거, 등급은 카드 색과 테두리로 표시.
- 모두 열기/진행 수/키보드 포커스/모션 축소 환경 지원. 열기 직후 건너뛰기 타이머 중복 방지.
- 작은 화면에서는 결과 카드 4열. 결과 영역은 스크롤 가능.
