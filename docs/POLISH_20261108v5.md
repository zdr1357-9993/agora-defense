## 실제 화면에서 확인한 문제
- 고민방 버튼의 `.t1` 등급 스타일이 border-left: 5px로 남아 캐릭터 왼쪽에 세로선이 표시됨.
- 25개 타일의 모서리 문양과 진한 격자선이 반복되어 배경보다 격자가 먼저 보임.
- 불투명하고 굵은 순환로, 단색 대기석, 작은 사각 장식이 별도로 붙은 인상.
- 16자 넘는 전투 대사를 코드에서 잘라 말줄임표로 대체. 이름도 5자를 넘으면 강제 축약.
- 도감 이름과 선택 정보에 오래된 nowrap/ellipsis 규칙이 남음.
- 대화창이 앱 폭보다 넓게 펼쳐지고 내레이션은 어두운 구형 스타일을 사용함.
- 모든 캐릭터의 진한 이름표가 겹쳐 화면의 문자 밀도가 높음.
- 설정의 표시 버전이 오래된 v3로 남음.

## 반영
- 고민방 등급 테두리 제거, 실제 스프라이트 확대, 말풍선 전체 문장 줄바꿈.
- 5시대 전용 전투 풍경 5장과 시대별 대기 벤치 5종을 이미지로 제작하여 적용.
- Canvas 가장자리에 풍경 여백을 확보. 좌표와 포인터 입력을 함께 조정.
- 바닥은 연속된 광장. 선택할 때만 옅은 배치 가이드 표시. 순환로 두께/농도 완화.
- 전체 캐릭터 이름표를 선택한 캐릭터로 제한. 상세 패널과 도감은 전체 이름 표시.
- 전투 대사는 실제 측정 폭에 따라 줄바꿈, 내용 손실 없음, 긴 문장은 최대 8초 표시.
- 스토리 대화창을 앱 폭 내 크림 패널로 정리하고 15px/넉넉한 행간 적용.
- 아이콘, 그림자, 정보 버튼, 카드 테두리 정리. 버전 표시는 v5로 동기화.
