# 후속 UX: 장별 이동 연출

- [ ] 쉬움·보통·어려움·불멸의 1~6장을 단계별로 진행하는 화면 흐름 설계
- [ ] 장을 누르면 장면이 위로 이동해 다음 단계로 넘어가는 전환 구현
- [ ] 현재 위치, 이전 장으로 돌아오기, 잠금 및 해금 상태 표시
- [ ] `prefers-reduced-motion`에서 전환 애니메이션 줄이기
- [ ] 실제 스토리 사건/20웨이브 전투와 일반 30웨이브 실험 셀을 별도 측정
- [ ] stage에서 실제 장 이동 및 모바일 화면 배치 검증

이번 대량 승률 실험에서는 실험 단위를 기존 6맵 S1–S6으로 유지한다.
