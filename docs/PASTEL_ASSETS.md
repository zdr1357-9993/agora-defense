## 이미지 제작 및 적용

기본 이미지 생성 기능으로 만든 실제 PNG를 WebP로 포맷 변환해 번들에 포함했다.
생성 프롬프트와 적용 파일 목록은 `artwork-prompts.json`에 기록했다.
배경·캐릭터·아이콘을 따로 적용하며, 화면을 한 장의 그림으로 덮지 않는다.

| 이미지 파일 | 수량 | 적용 |
| --- | ---: | --- |
| 캐릭터 4×4 atlas | 5 | 80종 전투·도감·카드·대화·고민방·스킨 |
| 시대별 여정 배경 | 5 | 고대·동양·중세·근대·현대, 스토리 배경·카드 |
| 고민방 배경 | 1 | 선택한 철학자 뒤 열린 서재 |
| 기억 배너 | 1 | 거장 초대 화면 |
| 도구 4×4 atlas | 1 | 실제 도구 16종 |
| 인터페이스 4×4 atlas | 1 | 메뉴·재화·조작 등 16종 |
| 적 5×5 atlas | 1 | 시대 5개 × 일반·빠름·탱크·떼·보스 |
| 제목 리본 | 1 | 여정 제목 배경 |

총 16개 이미지 파일에서 145개 개별 그래픽을 사용한다. WebP 합계 약 3MB.
캐릭터 ID 매핑은 `src/character-atlas.json`, 로더와 atlas 자르기는 `src/artwork.ts`.
외부 이미지 서버에 의존하지 않으며 Vite가 배포 파일명에 content hash를 붙인다.

## 시작 및 복구

`src/boot.ts`가 이미지를 읽은 후 게임을 시작해 이전 도트가 캐시에 남는 문제를 방지한다.
개별 이미지를 읽지 못하면 15초 이내에 기존 도트로 대체하고 게임은 시작한다.
플레이 데이터·캐릭터 ID·조합·확률·계정 구조는 변경하지 않았다.
Git 코드 버전 복구는 플레이어의 브라우저/서버 진행 기록을 되돌리지 않는다.

갈무리 글꼴은 npm 의존성을 통해 번들링하며 `public/licenses/Galmuri-OFL.md`에 원문 라이선스를 포함한다.
