## 근현대와 현대 분리

기존 S5와 1848~1968년 이야기, 기존 현대 분류 철학자들을 게임 내에서 `근현대`로 묶었다. 철학자 ID, 카드 수, 레벨, 장비, 스킨, 완료된 스테이지 ID는 바꾸지 않았다. S6 `연결된 세계의 광장`과 6장 `연결된 세계와 책임`을 추가했다. 이는 게임의 장 구분이며 보편적인 시대 구분을 주장하는 것은 아니다.

| 지점 | 사건 | 게임에서 묻는 문제 |
|---|---|---|
| P21 | 1989.11.09 베를린 장벽 국경 개방 | 제약이 사라지면 자유는 완성될까? |
| P22 | 1993.04.30 CERN의 웹 소프트웨어 공개 | 연결이 늘면 이해도 깊어질까? |
| P23 | 2015.12.12 파리협정 채택 | 미래 세대에 대한 책임은 어떻게 나눌까? |
| P24 | 2022.11.30 ChatGPT 공개 | 답을 맡겨도 판단의 책임은 남을까? |

새 현대 배경, 필터버블 관리자/자동응답의 신탁 보스 2종, 양방향 순환 경로와 보호막 기술을 연결했다. 신규 현대 장은 기존 철학자들의 기억으로 오늘의 질문을 탐구한다. 새 철학자 캐릭터를 추가한 버전은 아니다. 철학자 대사는 명시적인 상상 대화이며 해당 사건에 참여했다거나 실제로 한 말이라는 뜻이 아니다.

기존 P20 완료자는 보통 난이도 해금을 유지하고 바로 P21로 이어간다. 이야기 총 29개(시작 튜토리얼 5개 포함), 장 선택 7개(시작 포함), 본편 전투 맵 6개다. 근현대 철학자의 기존 고향 보너스는 유지하고, 현대에서는 근현대의 기억이 함께 +25%를 받는다고 UI에 표시했다.

## 이미지 제작 기록

내장 이미지 생성으로 세 자산을 새로 제작했다.

- `src/assets/enemies-v3.webp`: 투명 4열×6행 시트. 간단한 24px 느낌의 파스텔 도트, 6개 시대 소품, 역할별 실루엣, 배경/광원/텍스트 제외.
- `src/assets/arena-present-v3.webp`: 현대 공공 광장, 작은 컴퓨터 부스·태양광 쉼터·정원·배선. 중앙 비워 둔 조용한 파스텔 도트.
- `src/assets/present-bosses-v3.webp`: 투명 2열 시트. 필터 체를 든 관리자 로봇과 질문 표정의 자동응답 신탁 컴퓨터. 기존 보스와 같은 코믹한 작은 비율.
