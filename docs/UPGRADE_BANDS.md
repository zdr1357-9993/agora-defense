# 전투 구간 강화 (임시 밸런스)

강화 선택은 1–3성, 4–5성, 6–7성 세 구간으로 나뉜다. 한 번 선택하면 해당 구간의 **전장 배치 유닛 전원**이 각각 1레벨 오른다. 대기석 유닛과 이미 최대 레벨인 유닛은 대상·비용에서 제외한다. Lv.5 상한과 레벨당 공격력 +35% 효과, 기존 전투 `level` 필드를 그대로 사용해 세이브 형식은 바뀌지 않는다.

## 현재 임시 비용

| 구간 | 유닛 1명·1회 기준 | 근거 |
|---|---:|---|
| 1–3성 | 40G | 기존 소환 기본 비용 40G를 참고한 임시값 |
| 4–5성 | 200G | 기존 5성 강화 기준 비용 200G를 유지하고 4성에 확장 |
| 6–7성 | 650G | 기존 6성 400G와 7성 900G의 중간값 |

강화가 반복되면 각 유닛의 현재 레벨에 `+1`을 곱한다. `+` 등급 유닛은 기존 규칙대로 비용이 1.5배다. 따라서 화면의 총비용은 대상 수와 유닛별 현재 레벨에 따라 달라진다. 이 수치는 출시 밸런스가 아니며 `src/data.ts`의 `UPGRADE.bands`에서 구간별 `baseCost`를 조정한다.
