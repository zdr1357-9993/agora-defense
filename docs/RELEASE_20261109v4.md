# 20261109v4 · 현대 해금 조건

일반 계정은 이전 다섯 맵(S1 고대, S2 중세, S3 동양, S4 근대, S5 근현대)의 `어려움`을 전부 클리어해야 현대(S6)가 열린다. 현대 자신의 어려움 기록은 조건에 포함하지 않아 순환 잠금이 생기지 않는다.

- 현대 이야기 P21~P24와 본편 전투에 같은 해금 조건을 적용한다. 이야기의 앞 지점 완료 조건과 기존 난이도별 진행 순서도 유지한다.
- 현대 장을 눌러 조건을 확인할 수 있으며 `이전 5개 시대 어려움 3/5 클리어`처럼 진행도를 보여 준다.
- 화면 버튼 외 직접 전투 시작·이야기 시작·다음 맵 이동에도 잠금을 적용한다. 현대 레이드는 해금 전 일일 보스 후보에서 제외한다.
- 기존 카드·스킨·클리어 기록은 삭제하지 않는다. 이미 현대 이야기를 플레이한 기록이 있어도 일반 계정의 재입장은 새 어려움 조건을 따른다.
- 기존 관리자/QA 전체 해금 예외는 유지한다.

버전 `20261109v3`는 `backup/pre-20261109v4`에 보존했다.

검증: TypeScript/Vite 빌드, 5개 선행 맵의 32개 클리어 조합, S6 자체 기록 제외, 0/5·4/5 잠금 및 5/5 해금, 이야기 순서, 직접 전투/이야기 호출 차단, 7개 요일의 레이드 후보, 관리자 예외와 기존 저장 기록 보존 테스트 통과. 로그인한 실서비스 플레이 검수는 별도로 하지 않았다.
