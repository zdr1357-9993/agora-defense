# 20261109v2 · 스킬 구분과 전투 가독성

이전 버전: `20261109v1`, 백업 브랜치: `backup/pre-20261109v2`.

## 스킬 감사 결과

현재 엔진은 철학자당 하나의 자동 스킬을 가진다. 수동 액티브 버튼이나 독립 쿨다운 스킬을 새로 만들지는 않았다. 80명의 실제 `SKILLS[realName]`를 전부 확인해 아래처럼 구분했다. 피해·확률·발동 조건은 유지했다.

| 구분 | 실제 종류 | 표시 |
|---|---|---|
| 상시 패시브 | 공격력/속도 오라, 전체 둔화, 보스 특효, 고독 | 작은 고정 상태 배지. 선택 시 영향 범위. 시전 동작 없음 |
| 명중 패시브 | 둔화, 광역, 연쇄, 취약, 지속 피해, 누적 강화 | 명중 순간 작은 소품·상태 효과. 화면 혼잡을 막기 위해 연출 빈도 제한 |
| 조건부 발동 | 치명타, N번째 강타, 추가 공격, 기절, 처형, 처치 골드 | 실제 성공 순간 큰 고유 동작. 실패하거나 대사만 나올 때 발동하지 않음 |

일반 공격은 짧은 반동만 남겼다. 대사가 스킬 시전을 만들어내던 연결을 제거했다. 동시 고유 연출은 최대 6개, 명중 패시브보다 조건부 발동을 우선한다.

예: 소크라테스=명중 약화+작은 지팡이, 니체=치명 성공+큰 망치, 플라톤=광역 명중+세 권의 책, 공자=공격력 지원 상태. 기존 몸체+소품 프레임의 합성이며 80개의 독립 전신 시트는 아니다.

## 새 이미지

내장 이미지 생성으로 제작한 아틀라스를 실제 WebP 자산으로 묶었다. 6개 배경과 10개 보스다.

| 시대 | 풍경 | 보스 2종 |
|---|---|---|
| 고대 | 올리브 아고라 | 동굴의 그림자 군주 / 아테네 배심원단 |
| 동양 | 대나무 서원 | 형식주의 대감 / 과거시험 암기귀신 |
| 중세 | 회랑과 약초 정원 | 면죄부 대상인 / 마녀사냥꾼 |
| 근대 | 벽돌 공방과 계몽 도시 | 절대왕정 집행관 / 리바이어던 |
| 현대 | 게시판과 안테나가 있는 캠퍼스 | 허무의 사도 / 알고리즘 확증편향 괴물 |
| 보리수 이야기 P7 | 보리수 정원 | 동양 계열 적 |

기존 저장값이 그리스 시안이어도 그 선택은 고대에만 적용된다. 나머지 시대는 전용 배경을 사용한다. 기본 5개 전투 맵과 보리수 이야기를 각각 매핑했다. 같은 시대의 나머지 이야기 지점은 해당 시대 배경을 공유한다. 이야기 전용 보스 전원에게 별도의 시트를 그린 범위는 아니며, 정확한 이름의 10개 레이드·웨이브 보스를 새 시트에 연결하고 나머지는 시대별 디자인을 공유한다.

생성 프롬프트 요약: 배경은 2열×3행, 차분한 파스텔 도트, 장식은 바깥쪽, 중앙 전투 공간 확보, 그리스/서원/중세 회랑/공방/현대 캠퍼스/보리수. 보스는 투명 2열×5행, 각 이름의 소품과 실루엣을 달리한 작은 코믹 캐릭터, 과한 광원·배경·텍스트 제외. 자산 경로: `src/assets/arena-*-v2.webp`, `src/assets/raid-bosses-v2.webp`.

## 가독성 피드백과 수정

- 배경이 밝아도 글자를 읽도록 이름표를 불투명 크림색으로 변경. 긴 전투 이름은 2줄, 전체 이름은 선택 정보창.
- 대사를 전투판 아래 별도 영역으로 이동. 원문 줄바꿈과 스크롤을 지원하며 한 문장을 최소 6초 유지. 몬스터를 가리지 않음.
- 보스 체력바도 전투판 밖으로 이동해 상단 이동 경로 확보.
- 작은 회색 설명문은 진하게, 스킬 설명은 12px 및 스크롤로 바꾸고 실제 스킬 구분을 표시.
- 합성 재료의 발밑 금빛 고리와 깜빡임을 작은 고정 종이 탭으로 교체. 합성은 짧은 8개 픽셀 종잇조각으로 표시. 화면 흔들림 제거.
- 빈칸의 파란 원형 선택 버튼을 작고 조용한 네 귀퉁이 표시로 교체. 칸 가이드 명도 감소.
- 일반 피해 숫자는 숨기고 큰 피해 숫자의 동시 노출은 8개로 제한. 명중 섬광 크기·입자 수 감소.
- 브라우저 핀치 확대를 허용. 작은 기기에서는 확대해서 설명을 읽을 수 있음.

## 남은 UX 판단

1. 전투판이 작을 때 이름을 무조건 한 줄로 축소하면 재차 가독성이 나빠진다. 현재는 짧은 전투 이름 1~2줄과 전체 이름 정보창을 함께 쓴다. 비슷한 이름의 상위 변형은 등급 배지와 전체 이름으로 확인한다.
2. 배경은 시대 5종+보리수 1종이다. 25개 이야기 지점마다 완전히 독립된 배경이 필요하면 추가 제작 범위다.
3. 수동 액티브 버튼/쿨다운 추가는 밸런스 변경이므로 이 릴리스에서 만들지 않았다. 현재의 조건부 자동 발동과 구분해 설계할 필요가 있다.
4. 16명이 배치된 밀집 테스트를 확인했다. 25칸 전체·최저 높이의 실기기 터치 검수는 추가로 필요하다.

## 검증

- `npm run build`: TypeScript 및 Vite 통과.
- `node scripts/check-skill-visuals.mjs`: 80명 스킬 매핑, 실제 성공/실패 발동, 대사 분리, 시대 배경/이전 저장값 회귀 통과.
- 기존 smoke: 메뉴·여정·소환·합성 관련 렌더·뽑기·최애·스킨 회귀 통과.
- 로컬 테스트: 39개 이미지 로드, 5개 밀집 전투 렌더, 보스 10개 셀 및 일반 공격/대사/실제 발동 렌더 분리 통과.
- 브라우저에서 로컬 테스트 비교 페이지를 확인. 실제 로그인한 실서비스 플레이 캡처는 아님.
