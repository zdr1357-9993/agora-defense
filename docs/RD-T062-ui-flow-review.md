# RD-T062 화면·플레이 흐름 점검 및 수정

2026-11-24 · 개발 소스 수정 · 시각 검수 미완료 · push/배포/stage 반영 없음

실제 브라우저를 연결하고 기존 E2E를 시작하려 했으나 실행 환경 문제로 게임 전체를 플레이하지 못했다. 아래 흐름 결함은 코드와 회귀 검사로 확인했고, 화면 수정은 소스의 크기·넘침 규칙을 근거로 보완했다. 화면이 실제로 정상이라는 판정은 보류한다.

## 검사 결과

- `node node_modules/typescript/bin/tsc --noEmit`: 통과.
- `npm run test:ui-flow`: 통과. 실제 endBattle/playDialogue/resultPanel 함수를 추출해 패배·승리·튜토리얼·홈 취소·대사·광고 중복 탭 검사.
- `node qa/check-current-mechanics.cjs`: 통과. 처치 영감석, 영입 비용, 잠금/부족/빈자리 무과금, 구간 강화, 같은 시드 재현.
- `npm run e2e:layout -- --list`: 30개 테스트 등록 확인. 실행 통과 수가 아님.
- 기존 smoke E2E: Vite 시작 전 `@rollup/rollup-darwin-arm64` 누락으로 중단. roster/skill/gacha 검사도 같은 Vite 의존성으로 실행 불가.
- 브라우저 연결은 `Managed execution requires a usable CODEX_CLI_PATH`, 서버 SSH는 `Operation not permitted`로 실패. 서버에서 git status/커밋을 실행할 수 없어 미수행.

## 이어서 확인할 화면

`npm run e2e:layout -- --project=mobile`은 320×568, 390×844, 844×390, 1024×768, 768×1024에서 로그인, 홈 5개 탭, 설정, 전투 강화·문답 화면을 검사하고 캡처를 남긴다. 아직 실행되지 않았다. 환경 복구 뒤 실제 스토리 한 판과 결과→재도전→홈, 대사, 카드 넘기기를 직접 확인해야 한다.

## 내가 임의로 정한 것

- 기존 파스텔 도트 색·이미지·메뉴 구성·밸런스 유지.
- 좁은 HUD는 44px 터치 버튼을 유지하면서 줄바꿈.
- 세로 공간이 부족하면 전장을 없애지 않고 화면을 스크롤.
- 대사 탭 동작은 함수에 명시돼 있던 ‘전체 공개 후 다음 줄’ 규칙으로 복원.
