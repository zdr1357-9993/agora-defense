## 요청 반영
- 전투/대기석의 철학자 이름을 항상 표시. 전체 이름에 맞춰 폭/글자 크기 조정.
- 대사 글자 크기·행간 축소. 말풍선은 광장 안쪽에 배치해 바깥 몬스터 순환로를 덮지 않게 함.
- 여정은 시대 탭과 비선형 배치 지도로 변경. 지점을 누르면 최애 아바타가 목적지로 이동하고 출발 버튼이 선택 지점을 가리킴.
- 지점 선택과 전투 시작은 별도 동작. 일반 계정의 진행 순서/잠금은 유지. 잠긴 지점은 이유를 보여 줌.
- 그리스 기반 배경 5개 생성: 올리브 아고라, 에게해 항구, 월계수 학당, 노을 신전, 낙서 공책 아고라.
- 설정에서 5개 시안을 직접 바꿔 적용. 기본 01번. 이전 시대별 풍경도 선택 가능.
- 뽑기에는 국소 도트 별·등급별 작은 파편 연출 추가. 전체 화면 플래시·카메라 흔들림 없음.
- admin 역할만 숨은 철학자 포함 전원 공개·최소 1장 보유, 챌린지 이름 공개. 재접속 때 추가 누적 지급 없음. 서버 저장을 불러온 후에도 적용.
- 고민방에 최애 이름/상태, 전체 보유 철학자 선택 목록. 현재 최애는 빠른 선택에도 항상 포함.
- 스킨은 보유한 거장(6)·근원(7)만 착용·구매. 상점 대상 선택 가능. 낮은 등급에는 안내 표시.

## 시그니처 이미지와 코드
- 이미지 2장에 16모티프 × 4프레임 = 64프레임.
- 80명 모두에 motif/gesture/variant/duration을 명시적으로 매핑한 signature-profiles.json.
- 소크라테스 지팡이, 니체 망치, 플라톤 책 3권, 공자 죽간, 칸트 시계, 오컴 면도날 등.
- 신규 그림이 캐릭터 몸 전체를 다시 그린 80종 스프라이트 시트는 아님. 기존 캐릭터 자세 변화 + 새 소품 애니메이션 + 개별 궤적을 합성.
- 실제 shot 이벤트의 목표 좌표, skill 발동 대사 이벤트에 연결. 10개 동시 연출 상한과 연속 재시작 방지.
- 게임 공격력·확률·판정은 변경하지 않음. shot 이벤트에 연출용 목표 좌표만 추가.
- 어드민 설정의 ‘스킬 연출 미리보기’: 전원 선택, 3대표 바로가기, 자동 재생, 프레임 슬라이더. 미리보기는 재화/보유 기록을 변경하지 않음.
