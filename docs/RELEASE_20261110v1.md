## 수정

- 여정이 모든 시대에서 `greek-01`을 쓰던 연결 오류를 수정했다. 고대·중세·동양·근대·근현대·현대가 각각 전용 이미지를 사용한다.
- 현대 여정 전용 풍경을 새로 제작해 `src/assets/map-present-v5.webp`에 추가했다. 도서관·버스정류장·통신탑·강변 풍경, 빈 중앙 영역, 파스텔 도트 스타일을 사용했다. 원본 이미지는 내장 이미지 생성으로 제작하고 WebP로 변환했다. 전투·확률에는 영향이 없다.
- 기존 한 줄 안내 영역 옆에 `대사` 버튼을 추가했다. 최근 30개 대사를 생략 없이 읽고, 열어 둔 동안 전투만 일시정지한다. 닫으면 재개하며 다음 전투에서 기록을 비운다.
- 능력치·조합법은 상세보기에서 펼쳐 볼 수 있게 했다. 카드 삽화에 시대별 풍경을 연결하고, 굵은 테두리·반복 움직임을 완화했다.
- 10회 뽑기 결과는 5열에서 3열로 정리했다. 기존 두루마리·픽셀 등장 효과를 유지하며 고등급 카드의 반복 맥동을 제거했다.
- 대사 버튼을 포함하는 실제 안내 행과 표시되는 요소 수를 기준으로 필드 높이를 계산한다.
